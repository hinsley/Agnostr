# Agnostr link-preview Worker
This optional, separately deployed Worker returns text-only Open Graph / Twitter Card metadata for public HTTPS links. It has no push, KV, account, or subscriber bindings. It uses Cloudflare's strictly public fetch mode, rechecks each redirect, makes credential-free capped GETs and returns bounded plain text only. No images, scripts, or third-party embed frames are loaded. CORS is not authentication; per-address and per-location rate limits limit abuse, not the total account-wide Workers quota. Keep this separated from trusted backends, with no private network bindings. No request logs, durable cache, or private message payload beyond the manually requested URL.

Deploy from the checkout with the existing Wrangler installation: `push-bridge/node_modules/.bin/wrangler deploy --config link-preview/wrangler.toml`. Set the GitHub Pages build variable `VITE_LINK_PREVIEW_URL` to the resulting HTTPS URL plus `/preview`. Local Vite can use the same environment variable; the PWA stays on plain links when it is unset. Match `ALLOWED_ORIGINS` to the frontend. No plan changes are required by this code.

Install locked dependencies with `npm ci --prefix link-preview` and `npm ci --prefix push-bridge`. Run `npm test --prefix link-preview` for mocked redirect, rate-limit, parser and URL checks. To check the real chat UI, build the PWA with `VITE_LINK_PREVIEW_URL=http://127.0.0.1:4801/preview`, run Vite preview on localhost, and run `pwa-nostr-chat/scripts/check-link-previews-ui.mjs` from the PWA directory; it intercepts preview requests and relays in a disposable browser profile.

Cards appear for explicitly trusted senders and your own posts. Public feeds load near the viewport; encrypted chats and Agmail need a tap before the URL is sent. Unknown query parameters, likely authentication links, hidden spoilers, inline code, raw media links and internal AG links do not preview. A site's response can omit metadata or block crawlers; those messages retain their ordinary links. X posts are not embedded or looked up with the paid X API.
